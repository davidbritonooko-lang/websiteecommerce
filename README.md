# Abotik Shop — Frontend prototype

Responsive e-commerce storefront and visual admin dashboard built with Next.js, React and TypeScript.

## Current phase
Frontend only, with sample products and illustrative dashboard data. Search, category filtering and sorting run in the browser. No database, authentication, payment, order processing, persistent cart or secure admin access is connected yet. Do not use this prototype to accept real orders or customer data.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
```

Designed for deployment to Vercel using its standard Next.js preset. No environment variables are required for this frontend phase.
